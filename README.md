# Catch The Falling Stars

A simple game made with Python and Pygame.

## How to Play

- Press SPACE to start the game.
- Use LEFT and RIGHT arrow keys to move the basket.
- Catch the falling stars to increase your score.
- You can miss up to 5 stars.
- Press R to restart after Game Over.

## Built With

- Python
- Pygame

## How to Run

Install Pygame:

    pip install pygame-ce

Then run the game file.
